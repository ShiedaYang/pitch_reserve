# Pitch Reserve · 本地场地监测

单用户 Windows 本地控制台：四个普通租场入口、三组账号自动登录、手动接管、只读库存观察与官网跳转。**自动锁位未实现，程序不选中可订场次、不加购物篮、不提交预约或付款。**

需要 Node.js 24+、已安装 Microsoft Edge。首次安装并启动：

```powershell
npm install --cache .local/npm-cache
npm start
```

打开 <http://127.0.0.1:4318>。也可运行 `./start.ps1`。服务绑定127.0.0.1，非局域网服务。前台运行时按Ctrl+C正常保存退出；后台运行时可用`./stop.ps1`正常关闭（默认4318端口）。退出运行进程会停止监测；电脑睡眠期间无法检查。

## 登录与恢复

1. 展开对应网站的“账号密码自动登录”，输入账号和密码，点击“保存并自动登录”。GGCB、Tower Hamlets独立；PlayFootball两场地共用一组。也可以点击“手动接管”直接在官网登录。
2. 账号密码使用Windows DPAPI CurrentUser加密保存在`.local/credentials/`，重启后可点击“使用已保存账号登录”。没有明文密钥文件；更换Windows账户或系统后可能需要重新保存。点击“清除账号密码”删除本机密文及运行内存中的凭据，不会退出已有官网会话。请勿把`.local/`分享给他人。

保存后，网站卡片直接显示账号明文和“密码：••••••••（已保存）”；展开表单会自动填入保存的账号。圆点是固定长度的状态占位符，不是真实密码。刷新页面仍会显示，正在修改的账号不会被轮询覆盖；清除凭据后账号及密码占位提示一并消失。继续登录可点“使用已保存账号登录”，修改密码则在密码框输入新值并保存。
3. 回控制台点击“检测会话”，再“恢复监测”。登录状态未知不会伪装成成功；恢复只会读日历。
4. “打开官网并接管”也会暂停该网站；PlayFootball 两个入口共用同一会话与操作权。登录、付款或其他手动操作期间不自动刷新该网站页面。

Council卡片的“场地表单默认选项”显示本机保存的场地、开放时间、居民/队伍类别、更衣室、Third、Senior及队名。点击“应用默认选项并进入日历”才会把这些明确保存的值填入官网并通过普通Next继续；定时扫描不会运行这项操作。未保存地址默认值时不填写地址；不会自动确认条款，到达日历立即停止，需要补充个人资料时停下交人工。默认值存于本地SQLite，正常重启保留。

用户明确提供邮编后，可在`.local/council-address-defaults.json`保留默认邮编及官网地址选项标识。应用默认选项时使用官网查询，只有唯一有效地址或此前明确保存的选项才会选择；多个地址不猜选，查询失败不会套用旧邮编结果。不保存完整地址文本，不修改手动地址内容；该本机文件同样被Git忽略。地址选好后仅通过普通Next进入日历，不点时间或Confirm。

会话、加密凭据、SQLite和npm缓存存于`.local/`，已排除Git。检测到登录成功或正常关闭时保存官网会话；登录失效时最多尝试一次保留账号的自动登录。账号错误、验证码或安全验证会交回人工，不循环重试；验证码在官网输入。控制台API只返回已保存账号及保存状态，不返回密码；密码不存入浏览器localStorage/sessionStorage，不记录密码、验证码或银行卡，也不保存完整登录后页面HTML或网络请求。只有当前Windows用户可以解密凭据；以同一用户身份运行的软件仍属于同一信任边界。程序默认使用已安装的Edge；如需其他已安装通道，可设置`PITCH_BROWSER_CHANNEL=chrome`。

## 当前范围和限制

- 默认从启动日到两个月后，周一至周四伦敦当地18:00开始。控制台可设日期和10–120分钟检查间隔，默认15分钟。
- GGCB半场55分钟、Stepney三分之一场、Westferry普通5v5产品85、Poplar普通7v7产品88。只读版本不创建订单，每周最多一场的偏好已展示，但不宣称能阻止用户在官网手动另订。
- PlayFootball解析可见日历、明确的日期表头和18:00时间块，按目标范围尝试正常下一周按钮；到达官网边界后保留未确认状态，不推算库存。“Available nearby”不计为本场可订。每个可选场次读取其时长与英镑价格。
- GGCB按官网当前“下个月提前7天开放”规则标记未放号日期，不强翻未开放月份。月份请求失败时有界重载一次；等待对应日期请求及遮罩结束后读取时段，避免旧数据。只点日期，不点时间块和Book now；价格通过官网只读费用试算取得，不生成订单。
- Council已在用户登录、填写真实资格和联系资料后验证Stepney Green Third日历。只点击日期、Back和Earlier/Later；读取18:00的明确状态，不点击时间或Confirm。日期上的UNAVAILABLE不推断为已满，仍标注原因未明。
- Council目前未选择场次来核实实际租期及成交报价；如可见时段行展示唯一英镑金额则读取，否则明确显示价格待核实，不能用公开居民/非居民价猜测。页面的20分钟提示是表单时限，不能当作锁位证据。会话恢复后仍需人工核对真实资格、资料并进入Book pitch，不自动重填或提交个人资料。
- 点击可选场次会在工具的官网登录浏览器中打开固定场馆入口，并暂停该网站监测；不会选择时间或保留库存。日期、时间和结算价仍需人工在官网确认。旧观察会标记需重新查验。
- 日期未开放、导航失败和页面结构变化不会显示为售罄。部分覆盖是可见状态；并非已证明扫描完两个月。
- “可订”是页面观察，无库存保留和成交价格保证；GGCB55分钟需用户确认偏好。当前不接受任何自动锁位设置。

## 开发与验证

```powershell
npm run check
npm test
node scripts/verify-console.ts
```

`PITCH_START_PAUSED=1`可让服务启动时先暂停所有供应商，用于本地界面与API测试。`PORT`可调整本地端口。

代码分为持久化浏览器会话、三个网站适配器、监测调度、SQLite和静态网页。API只开放固定供应商的登录/打开/检测/恢复/暂停/扫描、只读表单结构检查及正常关闭操作，以Host/Origin和启动令牌保护修改请求。结构检查不读取密码或输入值，不保存完整页面。没有通用浏览器操作或任意URL接口。网站适配器按文件版本加载，调整日历解析后下次扫描即可使用，无需关闭已登录的浏览器。

前期证据和剩余验收项：[网站验证](docs/website-validation.md)、[技术设计](docs/technical-framework.md)。这些文件记录设计/研究阶段，实际实现状态以本README及运行结果为准。
